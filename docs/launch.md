# 首次发布分享草稿

## 中文短文案

我开源了一个本地素材工作台：**拾序 · Original Studio**。

有时记得画面，却忘了文件名；有时记得一句台词，却想不起出自哪个视频。拾序把图片、视频和文档放在同一套检索与整理流程里：

- 中文描述与参考图找相似图片、视频画面。
- 文档正文与视频台词检索，返回页码或时间点。
- 收藏、标签、备注和灵感集整理。
- 本机推理，原始素材保留在已有文件夹中。

当前是 Windows + Python 3.11 的源码预览版，采用 GPL-3.0-only。欢迎试用、反馈具体问题；如果对你有帮助，也欢迎 Star。

项目：https://github.com/LEAFSSSSS/OriginalStudio

下载：https://github.com/LEAFSSSSS/OriginalStudio/releases/latest

## 演示内容建议

使用自己可公开的少量素材，录制一段约 30 秒的真实操作：连接目录 → 扫描/建立索引 → 输入画面描述 → 打开结果 → 加入灵感集。将演示与项目链接一起分享给实际需要整理素材的人。

后续优先收集首次安装是否成功、第一次检索是否找到目标，以及哪些文件格式不能读取。把能复现的问题转成 Issues，持续在 Release 中说明改动。

思路参考 GitHub 的 [Finding Users for Your Project](https://opensource.guide/finding-users/)：明确用途，提供统一入口，并向有相关需求的群体收集反馈。
