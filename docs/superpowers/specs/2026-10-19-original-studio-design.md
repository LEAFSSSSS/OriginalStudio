# 拾序 Original Studio 独立重写设计

日期：2026-10-19。作者已在本次会话选择“按推荐方案独立完整重写”，以下是该方案的书面落实。

## 目标与边界

在 `G:/Material/OriginalStudio` 建立可独立启动的本地素材工作台。现有项目提供功能需求参考；新项目自行实现界面、接口、存储、索引和任务管理，不导入旧项目的应用模块，不连接旧索引数据库。第三方库和模型保留独立的来源记录。

交付范围包括图片、视频、文档目录管理；增量扫描；文件名和正文搜索；图文与参考图相似检索；视频抽帧与台词检索；收藏、标签、备注、集合及 CSV 导出；视频片段导出；索引任务停止、继续和失败重试；数据备份；源码安装和启动脚本。Pexels 历史数据库、付费激活、云同步和自动更新不在本次本地项目范围内。

## 结构

后端采用 Python 3.11、FastAPI 和 SQLite。每次数据库操作独立连接，启用 WAL、外键与超时；以版本号管理结构。素材路径和整理元数据保存在新数据库。文档和台词片段以 SQLite FTS5 trigram 索引；不足三个字符的中文查询采用转义后的包含查询。图片向量保存为归一化 float32 数据，分批计算余弦相似度。

单个持久任务队列串行执行扫描、视觉索引、文档索引、语音索引和失效索引清理。每个文件单独记录结果，意外退出将运行任务标记为已中断，可继续执行；停止请求在文件和帧边界检查。原文件只读取，片段导出写入程序自身的输出目录。

图文模型和语音模型通过独立适配器延迟加载。文件列表、文档检索、整理功能启动时不加载 PyTorch。未安装可选依赖时，界面显示真实状态和安装命令。模型签名写入视觉索引，模型改变后拒绝混用向量。

## 界面

原生 ES modules、HTML 和 CSS，无前端构建或远程 CDN。深色左侧栏显示素材目录、收藏、集合和任务；主区域是浅色搜索工作台，提供文件名、画面描述、参考图片、文档正文和视频台词模式。结果卡片和列表可切换，详情抽屉编辑收藏、标签、备注和集合。空状态指导添加目录及建立对应索引，不展示伪造素材。

支持中文路径、键盘操作、可访问的弹窗与焦点返回、移动窄屏布局、请求中/失败/空结果状态。界面状态与 URL 查询参数同步，目录和视图偏好可保存至 localStorage。

## 本机接口边界

默认监听 `127.0.0.1:8090`。校验 Host、Origin 与本机会话凭据；改变状态的操作使用 POST/PATCH/DELETE。媒体路由只接受数据库素材编号，并在读取时核对真实路径仍属于注册目录。参考图限制大小、验证解码并重新编码。SQL 查询使用参数，HTML 使用文本节点或转义。清理只处理索引与程序缓存。

## 验收

使用临时目录和合成素材验证扫描、增量更新、中文正文检索、分页、路径边界、收藏持久化、集合导出、任务恢复、错误输入及源文件完整性。若本机具有模型和可选运行库，再执行独立小样本的真实图文检索，结果不作为实际素材准确率或性能保证。检查实际页面的空状态、目录添加、搜索、详情编辑与窄屏布局。交付说明区分已验证功能和需要额外环境的能力。
